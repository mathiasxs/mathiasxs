### Mathias Schütz

Senior software developer. Angular and TypeScript by trade, currently moving into the backend.

For the past eight years I have built enterprise content management software — first as the
only developer in a regional subsidiary, where a one-off solution for a single customer
turned into a product that sold five times over, then in Berlin on a web client used by
around half a million people, and now on the admin applications replacing a Windows toolset
that has been growing since the 1990s. What colleagues usually pull me into is not the
framework question. It is the one underneath it: whether a technical solution actually fits
the way the product gets used.

Angular is where I make the calls — repository structure, going module-free, a shell that
carries five legacy applications in its belly, and the occasional well-argued no. Right now
I am deliberately moving the other way, into Java and Spring Boot, because I would rather
own a system end to end than half of one.

Most of the code my team ships is now written with Claude Code. I set it up for us, wrote
the first CLAUDE.md and the docs that make it hold together, and I review and answer for
every line that goes out. The speed is not the interesting part. Keeping an architecture
coherent when typing is no longer the bottleneck — that is.

Off the clock I build things that have to keep running without me: a Raspberry Pi picture
frame that pulls from a shared iCloud album and never goes black, a few home servers, and
earlier a crypto wallet built on Shamir Secret Sharing that shipped with its own store.

**Currently:** backend work, and building things with LLM APIs on the side.
